Clyvexis Glossary

Learn the important words, concepts, technologies, attacks, defenses, and tools used in cybersecurity.

🔎
#001 • FUNDAMENTALS

Cybersecurity

The practice of protecting computers, networks, systems, accounts, and data from digital threats.

Example: Protecting a website from unauthorized access.
#002 • FUNDAMENTALS

Threat

Something that could potentially cause harm to a computer system, network, account, or piece of information.

Example: Malware can be a threat to a computer.
#003 • FUNDAMENTALS

Vulnerability

A weakness in software, hardware, configuration, or a process that could potentially be exploited.

Example: Outdated software may contain vulnerabilities.
#004 • FUNDAMENTALS

Risk

The possibility that a threat could take advantage of a vulnerability and cause harm.

Example: An unpatched server may create security risk.
#005 • FUNDAMENTALS

Asset

Something valuable that needs protection. Assets can include data, devices, accounts, applications, and networks.

Example: A company's customer database is an asset.
#006 • FUNDAMENTALS

CIA Triad

Confidentiality, Integrity, and Availability. These are three major goals of cybersecurity.

Example: Security teams use the CIA Triad when designing protections.
#007 • FUNDAMENTALS

Confidentiality

Making sure information is only accessible to people or systems that are authorized.

Example: Passwords help keep private accounts confidential.
#008 • FUNDAMENTALS

Integrity

Making sure information remains accurate and has not been changed without authorization.

Example: Hashes can help detect unexpected changes.
#009 • FUNDAMENTALS

Availability

Making sure systems and information are available when authorized users need them.

Example: Backup systems can help maintain availability.
#010 • FUNDAMENTALS

Cyber Attack

An attempt to gain unauthorized access, steal information, disrupt systems, or cause other digital harm.

Example: A criminal attempting to access an account.
#011 • NETWORKING

Network

A group of connected devices that can communicate and share information.

Example: Computers connected to the same Wi-Fi network.
#012 • NETWORKING

IP Address

A numerical address used to identify a device or network interface on a network.

Example: 192.168.1.10 can be a private IPv4 address.
#013 • NETWORKING

IPv4

A common version of Internet Protocol that uses 32-bit addresses.

Example: 8.8.8.8 is an IPv4 address.
#014 • NETWORKING

IPv6

A newer version of Internet Protocol that uses 128-bit addresses.

Example: IPv6 provides a much larger address space.
#015 • NETWORKING

DNS

Domain Name System. It translates domain names into IP addresses.

Example: DNS helps your browser find the server behind a website name.
#016 • NETWORKING

Router

A device that forwards network traffic between different networks.

Example: A home router connects your devices to the internet.
#017 • NETWORKING

Firewall

A security system that monitors and controls network traffic based on rules.

Example: A firewall can block unwanted network connections.
#018 • NETWORKING

Port

A logical communication endpoint used by network services.

Example: HTTPS commonly uses TCP port 443.
#019 • NETWORKING

TCP

Transmission Control Protocol. It provides reliable, ordered communication between devices.

Example: TCP helps ensure data arrives correctly.
#020 • NETWORKING

UDP

User Datagram Protocol. A faster, connectionless network protocol.

Example: UDP is commonly useful when speed matters.
#021 • AUTHENTICATION

Authentication

The process of verifying who a user or system claims to be.

Example: Logging into an account with a password.
#022 • AUTHENTICATION

Authorization

Determining what an authenticated user or system is allowed to access or do.

Example: An employee may be allowed to view certain files but not others.
#023 • AUTHENTICATION

MFA

Multi-Factor Authentication requires multiple types of verification.

Example: Password plus a verification code.
#024 • AUTHENTICATION

Biometrics

Authentication using physical or behavioral characteristics.

Example: Fingerprint or facial recognition.
#025 • AUTHENTICATION

Password Manager

Software designed to securely store and manage passwords.

Example: A password manager can generate unique passwords.
#026 • AUTHENTICATION

Least Privilege

Giving users and systems only the access they need to perform their job.

Example: A student account does not need administrator access.
#027 • AUTHENTICATION

Access Control

Rules and technologies used to control who can access resources.

Example: File permissions control who can open a document.
#028 • CRYPTOGRAPHY

Encryption

Converting readable information into a protected form that requires the appropriate key to decrypt.

Example: HTTPS protects information sent between your browser and a website.
#029 • CRYPTOGRAPHY

Decryption

The process of converting encrypted information back into a readable form.

Example: An authorized system decrypts protected data.
#030 • CRYPTOGRAPHY

Hash

A fixed-length value generated from data using a hash function.

Example: SHA-256 can create a hash from text.
#031 • CRYPTOGRAPHY

SHA-256

A widely used cryptographic hash algorithm that produces a 256-bit hash.

Example: It can be used to verify that data has not changed.
#032 • CRYPTOGRAPHY

Encryption Key

A value used by an encryption algorithm to protect or recover information.

Example: A system may use a key to encrypt stored data.
#033 • CRYPTOGRAPHY

Symmetric Encryption

Encryption where the same secret key is used for encryption and decryption.

Example: AES is a symmetric encryption algorithm.
#034 • CRYPTOGRAPHY

Asymmetric Encryption

Encryption that uses a related public key and private key.

Example: Public-key cryptography is used in many secure systems.
#035 • CRYPTOGRAPHY

Digital Signature

A cryptographic mechanism used to help verify authenticity and integrity.

Example: Software publishers can digitally sign applications.
#036 • CRYPTOGRAPHY

Certificate

A digital document used to associate an identity with a public key.

Example: Websites use certificates with HTTPS.
#037 • MALWARE

Malware

Malicious software designed to disrupt, damage, spy on, or gain unauthorized access to systems.

Example: Viruses and ransomware are types of malware.
#038 • MALWARE

Virus

A type of malware that can attach itself to files or programs and spread when executed.

Example: A malicious file could carry a virus.
#039 • MALWARE

Worm

Malware capable of spreading between systems without needing to attach to another file.

Example: A worm may spread through vulnerable systems.
#040 • MALWARE

Trojan

Malware that disguises itself as something legitimate or useful.

Example: A fake application could contain a Trojan.
#041 • MALWARE

Ransomware

Malware that can make data or systems inaccessible and demands payment from victims.

Example: Organizations prepare backups to help recover.
#042 • MALWARE

Spyware

Malware designed to secretly monitor activity or collect information.

Example: Spyware may attempt to collect sensitive information.
#043 • MALWARE

Keylogger

Software or hardware designed to record keyboard input.

Example: Security software can detect some keylogging threats.
#044 • MALWARE

Botnet

A group of compromised devices controlled by an attacker.

Example: Botnets can be used to generate large amounts of unwanted traffic.
#045 • SOCIAL ENGINEERING

Phishing

A scam that attempts to trick people into revealing information or taking an unsafe action.

Example: A fake login email asking for account information.
#046 • SOCIAL ENGINEERING

Spear Phishing

A targeted phishing attempt designed for a particular person or organization.

Example: A scam message customized for a specific employee.
#047 • SOCIAL ENGINEERING

Smishing

Phishing delivered through text messages or SMS.

Example: A fake delivery text asking you to click a link.
#048 • SOCIAL ENGINEERING

Vishing

A social engineering scam conducted through voice calls.

Example: Someone pretending to be a legitimate company over the phone.
#049 • SOCIAL ENGINEERING

Pretexting

Creating a believable story or situation to manipulate someone into providing information.

Example: Someone falsely claiming to be technical support.
#050 • SOCIAL ENGINEERING

Baiting

Using something attractive or interesting to trick someone into taking an unsafe action.

Example: A suspicious download advertised as something desirable.
#051 • ATTACKS

Brute Force

An attack that repeatedly tries many possible passwords or authentication values.

Defense: Strong passwords, MFA, and rate limiting help.
#052 • ATTACKS

Credential Stuffing

Attempting to use stolen username and password combinations on other services.

Defense: Use unique passwords for every account.
#053 • ATTACKS

DDoS

Distributed Denial-of-Service attacks attempt to overwhelm a service with large amounts of traffic.

Defense: Traffic filtering and mitigation services can help.
#054 • ATTACKS

Man-in-the-Middle

A situation where an attacker attempts to intercept communications between parties.

Defense: Encryption and secure protocols help protect communications.
#055 • ATTACKS

SQL Injection

An attack involving malicious input that attempts to manipulate database queries.

Defense: Parameterized queries and input validation help.
#056 • ATTACKS

Cross-Site Scripting

A web security issue where untrusted content can cause unwanted scripts to run in a user's browser.

Defense: Output encoding and secure web development practices.
#057 • ATTACKS

Zero-Day

A vulnerability that is unknown or has not yet been fully addressed by the affected vendor.

Example: Security teams monitor for newly discovered vulnerabilities.
#058 • ATTACKS

Exploit

Code, data, or a technique that takes advantage of a vulnerability.

Example: A security update may fix the weakness an exploit targets.
#059 • DEFENSE

Patch

A software update that fixes bugs, vulnerabilities, or other problems.

Example: Installing operating system security updates.
#060 • DEFENSE

Antivirus

Security software designed to detect, block, and remove certain malicious software.

Example: Antivirus software can scan files for threats.
#061 • DEFENSE

EDR

Endpoint Detection and Response tools monitor endpoint activity and help security teams investigate threats.

Example: EDR can help investigate suspicious activity on computers.
#062 • DEFENSE

Backup

A separate copy of important data that can be used for recovery.

Example: Backups can help recover after data loss.
#063 • DEFENSE

Security Policy

A set of rules and guidelines explaining how an organization protects systems and information.

Example: A company may have a password policy.
#064 • DEFENSE

Defense in Depth

Using multiple layers of security so one failed protection does not expose everything.

Example: MFA plus firewalls plus monitoring.
#065 • DEFENSE

Security Awareness

Training people to recognize and respond safely to security threats.

Example: Learning how to recognize phishing messages.
#066 • WEB SECURITY

HTTP

Hypertext Transfer Protocol is used for communication between web clients and servers.

Example: Browsers use HTTP-based requests to retrieve web resources.
#067 • WEB SECURITY

HTTPS

HTTP protected using TLS encryption.

Example: Secure websites commonly begin with HTTPS.
#068 • WEB SECURITY

Cookie

Small pieces of information that websites can store in a browser.

Example: Cookies can help maintain a login session.
#069 • WEB SECURITY

Session

A period of interaction between a user and an application.

Example: A website can maintain a user's signed-in session.
#070 • WEB SECURITY

API

Application Programming Interface. A defined way for software systems to communicate.

Example: A website can use an API to request information.
#071 • WEB SECURITY

Input Validation

Checking user-provided information before allowing an application to process it.

Example: A form can verify that an email field contains a valid format.
#072 • WEB SECURITY

CORS

Cross-Origin Resource Sharing controls certain cross-origin browser requests.

Example: A server can specify which origins may access resources.
#073 • CLOUD

Cloud Computing

Using computing resources such as servers, storage, and databases over a network.

Example: Hosting an application on a cloud platform.
#074 • CLOUD

Cloud Storage

Storing data on remote systems that can be accessed through a network.

Example: Online file storage services.
#075 • CLOUD

IaaS

Infrastructure as a Service provides computing infrastructure through a service.

Example: Renting virtual servers from a cloud provider.
#076 • CLOUD

PaaS

Platform as a Service provides tools and infrastructure for developing applications.

Example: Developers can deploy applications without managing every underlying server.
#077 • CLOUD

SaaS

Software as a Service provides software through a network rather than requiring local installation.

Example: Web-based productivity applications.
#078 • SECURITY OPERATIONS

SOC

Security Operations Center. A team or facility responsible for monitoring and responding to security events.

Example: Analysts investigate suspicious activity.
#079 • SECURITY OPERATIONS

SIEM

Security Information and Event Management systems collect and analyze security-related logs.

Example: A SIEM can help analysts investigate alerts.
#080 • SECURITY OPERATIONS

Log

A recorded event or activity generated by a system, application, or device.

Example: Login attempts can be recorded in logs.
#081 • SECURITY OPERATIONS

Alert

A notification that potentially suspicious or important activity has been detected.

Example: A security system may alert analysts about unusual login activity.
#082 • SECURITY OPERATIONS

Incident Response

The organized process of detecting, analyzing, containing, and recovering from security incidents.

Example: A security team investigates a compromised account.
#083 • SECURITY OPERATIONS

Threat Intelligence

Information about threats that helps security teams understand and prepare for attacks.

Example: Analysts track information about emerging threats.
#084 • SECURITY OPERATIONS

IOC

Indicator of Compromise. Evidence that may suggest a system has been affected by a security incident.

Example: A suspicious file hash can be an IOC.
#085 • FORENSICS

Digital Forensics

The process of collecting and analyzing digital evidence.

Example: Investigators may examine system logs after an incident.
#086 • FORENSICS

Digital Evidence

Information stored or transmitted digitally that may help answer questions during an investigation.

Example: Logs can provide evidence about system activity.
#087 • FORENSICS

Chain of Custody

Documentation showing how evidence was collected, handled, transferred, and stored.

Example: Investigators document who handled evidence.
#088 • FORENSICS

Metadata

Information that describes other data.

Example: A photo can contain information about its creation time.
#089 • CAREERS & TOOLS

Ethical Hacker

A security professional who is authorized to test systems for weaknesses.

Example: A company may hire an ethical hacker to test its security.
#090 • CAREERS & TOOLS

Penetration Testing

Authorized security testing designed to identify and evaluate weaknesses.

Example: A security team tests a company's own application.
#091 • CAREERS & TOOLS

Vulnerability Scanner

A tool that searches systems or applications for known security weaknesses.

Example: A scanner can identify outdated software.
#092 • CAREERS & TOOLS

Network Administrator

A professional who manages and maintains computer networks.

Example: Managing routers, switches, and network access.
#093 • CAREERS & TOOLS

Security Analyst

A cybersecurity professional who monitors, investigates, and helps respond to security threats.

Example: An analyst investigates suspicious login alerts.
#094 • CAREERS & TOOLS

Security Engineer

A professional who designs, builds, and maintains security systems.

Example: Building secure network or cloud infrastructure.
#095 • CAREERS & TOOLS

Incident Responder

A cybersecurity professional who helps investigate and respond to security incidents.

Example: Helping an organization recover from a security event.
#096 • CAREERS & TOOLS

Python

A programming language widely used for automation, data analysis, security tools, and many other tasks.

Example: Python can automate repetitive security tasks.
#097 • CAREERS & TOOLS

Linux

A family of open-source operating systems commonly used in servers, development, networking, and cybersecurity.

Example: Many security professionals use Linux environments.
#098 • CAREERS & TOOLS

Command Line

A text-based interface used to interact with an operating system or program.

Example: Commands can be used to navigate files and inspect system information.
#099 • CAREERS & TOOLS

Git

A version control system used to track changes to files and software projects.

Example: Developers use Git to manage code changes.
#100 • CAREERS & TOOLS

GitHub

A platform for hosting and collaborating on software projects using Git.

Example: Clyvexis website files can be stored in a GitHub repository.
