Cybersecurity Glossary

Learn the important words and concepts used by cybersecurity professionals.

Authentication

Verifying that a person or system is really who or what it claims to be.

Security

Encryption

Converting readable information into protected information that requires the correct method or key to read.

Security

Hashing

Turning data into a fixed-length value called a hash. Hashing is commonly used to protect passwords and verify data.

Security

Firewall

A security system that monitors and controls network traffic according to security rules.

Security

Vulnerability

A weakness in software, hardware, configuration, or a process that could create a security risk.

Security

Patch

A software update that can fix bugs and security vulnerabilities.

Security

Zero-Day

A previously unknown or unpatched vulnerability that may be exploited before a fix is available.

Security

Antivirus

Software designed to detect, block, and remove certain types of malicious software.

Security

Penetration Testing

Authorized security testing used to find weaknesses in systems and applications.

Security

Least Privilege

A security principle where users and systems receive only the access they need.

Security

Incident Response

The process of detecting, investigating, containing, and recovering from cybersecurity incidents.

Security

MFA

Multi-Factor Authentication uses two or more different verification methods to protect an account.

Identity

Authorization

Determines what an authenticated person or system is allowed to access or do.

Identity

Password Manager

A tool that securely stores and manages passwords and other login information.

Identity

Access Control

Security rules that determine who can access systems, information, or resources.

Identity

IP Address

A numerical address used to identify a device or network interface.

Network

DNS

The Domain Name System translates domain names into IP addresses.

Network

VPN

A Virtual Private Network creates an encrypted connection between a device and a network service.

Network

Packet

A small unit of data sent across a computer network.

Network

Network Security

The practice of protecting networks, devices, and network traffic from unauthorized access and attacks.

Network

Port

A logical communication endpoint used by network services and applications.

Network

Phishing

A scam that attempts to trick people into revealing information or interacting with something unsafe.

Attack

Spear Phishing

A targeted phishing attack designed for a specific person or organization.

Attack

Social Engineering

Manipulating people into revealing information or taking actions that create a security risk.

Attack

Brute Force Attack

An attack that repeatedly tries possible passwords or authentication values.

Attack

DDoS

A Distributed Denial-of-Service attack attempts to overwhelm a service with large amounts of traffic.

Attack

Spoofing

Making information or an identity appear to come from a trusted source when it does not.

Attack

Man-in-the-Middle

An attack where someone secretly interferes with communication between two parties.

Attack

Malware

Malicious software designed to disrupt systems, steal information, or perform unwanted actions.

Malware

Ransomware

Malware that prevents access to data or systems and attempts to pressure victims into paying money.

Malware

Spyware

Software designed to secretly collect information about a person or system.

Malware

Trojan

Malware that disguises itself as legitimate software or a file.

Malware

Worm

Malware capable of spreading between systems.

Malware

Botnet

A collection of compromised devices that can be controlled by an attacker.

Malware

Keylogger

Software or hardware designed to record keyboard input.
