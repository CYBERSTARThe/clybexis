Cybersecurity Lessons

Build your cybersecurity knowledge from the basics to more advanced concepts.

Lesson 01

What Is Cybersecurity?

Cybersecurity is the practice of protecting computers, networks, accounts, applications, and information from digital threats.

  • What cybersecurity protects
  • Common cyber threats
  • Why security matters
  • Examples of security controls
Lesson 02

Phishing

Phishing is a social-engineering technique where attackers attempt to trick people into revealing information or interacting with something unsafe.

  • Email phishing
  • Spear phishing
  • Fake login pages
  • Warning signs
Lesson 03

Strong Passwords

Strong passwords help protect accounts from unauthorized access. Good password practices are an important part of cybersecurity.

  • Use unique passwords
  • Use long passphrases
  • Avoid reused passwords
  • Use a password manager
Lesson 04

Multi-Factor Authentication

Multi-Factor Authentication, or MFA, adds another verification step to an account. This can make unauthorized access harder.

  • Something you know
  • Something you have
  • Something you are
  • Why MFA matters
Lesson 05

Malware

Malware is malicious software designed to perform unwanted or harmful actions on a computer or other device.

  • Viruses
  • Worms
  • Trojans
  • Ransomware
  • Spyware
Lesson 06

Network Security

Network security focuses on protecting networks, devices, communications, and services from unauthorized activity.

  • Firewalls
  • IP addresses
  • Ports
  • Network traffic
Lesson 07

Encryption

Encryption transforms readable information into protected data so that unauthorized people cannot easily understand it.

  • Plaintext
  • Ciphertext
  • Encryption keys
  • Secure communication
Lesson 08

Hashing

Hashing converts data into a fixed-size value. Hashes are commonly used for checking data integrity and protecting stored passwords.

  • Hash functions
  • SHA-256
  • Data integrity
  • Password storage
Lesson 09

Firewalls

A firewall monitors and controls network traffic according to a set of security rules.

  • Inbound traffic
  • Outbound traffic
  • Security rules
  • Network protection
Lesson 10

Social Engineering

Social engineering focuses on manipulating people rather than directly attacking technology.

  • Trust manipulation
  • Urgency
  • Impersonation
  • Recognizing suspicious requests
Lesson 11

Incident Response

Incident response is the organized process used to detect, investigate, contain, and recover from cybersecurity incidents.

  • Detection
  • Investigation
  • Containment
  • Recovery
Lesson 12

Vulnerabilities & Patching

A vulnerability is a weakness that could create a security risk. Patches can fix vulnerabilities and other software problems.

  • Security weaknesses
  • Software updates
  • Vulnerability management
  • Security maintenance
