What Is Cybersecurity?

Learn what cybersecurity is, why it matters, and what security professionals work to protect.

FUNDAMENTALS ~5 min
Key concept: Cybersecurity protects information, systems, devices, networks, and people from security threats.

Think about cybersecurity as a collection of layers rather than one single tool.
🎣

Phishing

Learn how deceptive messages and websites can be used to manipulate people.

THREATS ~6 min
Key concept: Phishing attacks often create urgency, fear, curiosity, or trust.

Learn to pause, inspect unexpected requests, and verify information through trusted channels.
🔐

Strong Passwords

Understand why unique passwords and password managers can improve account security.

ACCOUNT SECURITY ~5 min
Key concept: Reusing the same password across multiple accounts increases the potential impact if one account is compromised.
📱

Multi-Factor Authentication

Learn how MFA adds another layer of protection when signing into an account.

AUTHENTICATION ~5 min
Key concept: Authentication factors can include something you know, something you have, or something you are.
🦠

Malware

Explore malicious software and common categories such as viruses, worms, and trojans.

THREATS ~7 min
Key concept: Malware is a broad category. Different types can have very different behaviors and impacts.
🌐

Network Security

Learn why networks need security controls and how defenders protect connected systems.

NETWORKS ~7 min
Key concept: Network security combines technologies, rules, monitoring, and good security practices.
02

🔵 Intermediate

Understand attacks and defense

🔒

Encryption

Learn how encryption protects information by transforming readable data into protected data.

CRYPTOGRAPHY ~8 min
Key concept: Encryption is designed so that protected information cannot be easily understood without the appropriate key.
#️⃣

Hashing

Understand how hash functions produce fixed-size values and why hashing matters in security.

CRYPTOGRAPHY ~8 min
Key concept: A cryptographic hash produces a value from input data. Even a small input change can produce a very different result.
🧱

Firewalls

Learn how firewalls can filter network traffic according to defined security rules.

DEFENSE ~7 min
Key concept: Firewalls can enforce rules about network traffic, but they are only one part of a layered security strategy.
🧠

Social Engineering

Discover how attackers can manipulate people rather than directly attacking technology.

HUMAN FACTORS ~7 min
Key concept: Security awareness matters because technology can be undermined by human manipulation.
🚨

Incident Response

Learn the basic defensive process for identifying, containing, investigating, and recovering from incidents.

DEFENSE ~8 min
Key concept: Good incident response uses an organized process instead of making random decisions under pressure.
🔧

Vulnerabilities & Patching

Learn what vulnerabilities are and why updates help reduce security risk.

VULNERABILITIES ~7 min
Key concept: Software vulnerabilities can create security weaknesses. Timely updates can reduce exposure to known problems.
👤

Authentication vs Authorization

Understand the difference between proving who you are and deciding what you can access.

ACCESS CONTROL ~6 min
Remember: Authentication asks: “Who are you?”

Authorization asks: “What are you allowed to access?”
🚪

Access Control

Learn how organizations decide which users, systems, and services can access resources.

SECURITY ~7 min
Key concept: Access control reduces unnecessary access and helps organizations protect sensitive resources.

🟣 Advanced

Think like a security analyst

⚖️

Least Privilege

Learn why users and systems should receive only the access they actually need.

ACCESS CONTROL ~7 min
Key concept: Limiting unnecessary privileges can reduce the potential impact of mistakes or compromised accounts.
🔗

VPNs

Understand the basic purpose of VPNs and how they can create protected network connections.

NETWORKS ~7 min
Key concept: VPNs can help create encrypted connections, but using a VPN does not automatically make every aspect of online activity secure.
📡

DNS

Learn how the Domain Name System helps translate domain names into IP addresses.

NETWORKS ~8 min
Key concept: DNS makes the internet easier to use by connecting human-readable names with network addresses.
🏷️

IP Addresses

Learn what IP addresses are and how they help devices communicate across networks.

NETWORKING ~7 min
Key concept: IP addresses help identify network interfaces so information can be routed between systems.
🌊

DDoS Attacks

Understand distributed denial-of-service attacks and the defensive goal of maintaining availability.

THREATS ~8 min
Key concept: DDoS attacks attempt to overwhelm a service with large amounts of traffic or requests.
🔴

Ransomware

Learn how ransomware can disrupt organizations and why layered defenses and backups matter.

THREATS ~8 min
Key concept: Strong security combines prevention, detection, response, recovery, and reliable backups.

SECURITY MINDSET

Start Thinking Like a Defender

Cybersecurity isn't only about knowing tools. It's about learning how to recognize risk and make good decisions.

🧠 Ask Better Questions

Security professionals constantly question assumptions and investigate unusual behavior.

  • What am I protecting?
  • What could go wrong?
  • Who should have access?
  • How would I detect a problem?

🛡️ Think in Layers

Strong security rarely depends on one single control. Multiple layers can provide better protection.

  • Strong authentication
  • Access controls
  • Network defenses
  • Monitoring and response
