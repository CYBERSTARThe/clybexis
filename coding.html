Lesson 1 — 🧱 HTML Basics

📖 Learn

HTML stands for HyperText Markup Language. It creates the structure of a webpage. Think of HTML as the skeleton of your website. It tells the browser what elements should appear on the page. 

<h1>My Website</h1>

<p>Welcome to my website!</p>

<button>Click Me</button>

🧪 Challenge

What HTML tag is normally used for the main/largest heading?

Lesson 2 — 🎨 CSS Basics

📖 Learn

CSS stands for Cascading Style Sheets. CSS controls how your HTML looks. You can use CSS to change colors, fonts, spacing, borders, layouts, backgrounds, and animations. 

body {
    background: #050b16;
    color: white;
}

h1 {
    color: #00aaff;
}

🧪 Challenge

What does CSS control?

Lesson 3 — ⚡ JavaScript Basics

📖 Learn

JavaScript is a programming language that can make webpages interactive. It can respond to button clicks, change webpage content, perform calculations, and control different behaviors. 

let score = 10;

if (score >= 10) {

    console.log("Great job!");

}

🧪 Challenge
