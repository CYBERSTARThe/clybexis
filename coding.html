Lesson 1 — 🧱 HTML Basics

📖 Learn

HTML is the language used to create the structure of a webpage. Think of HTML as the skeleton of a website. It tells the browser where headings, paragraphs, buttons, images, and other elements belong. 

<h1>My Website</h1>

<p>Welcome to my website!</p>

<button>Click Me</button>

🧪 Challenge

What HTML tag is normally used for the largest/main heading?

Lesson 2 — 🎨 CSS Basics

📖 Learn

CSS controls how your HTML looks. You can use CSS to change colors, fonts, backgrounds, spacing, borders, layouts, and animations. 

body {
    background: #050b16;
    color: white;
}

h1 {
    color: #00aaff;
}

🧪 Challenge

What does CSS control?

Lesson 3 — ⚡ JavaScript Basics

📖 Learn

JavaScript is a programming language that allows websites to respond to users and perform actions. 

let score = 10;

if (score >= 10) {
    console.log("Great job!");
}
