Learn the coding skills behind websites, cybersecurity tools, games, and technology. Start with HTML, move into CSS, and then learn JavaScript.

🧱 HTML — Build the Structure

HTML is the language used to create the structure of webpages.

HTML 01

What Is HTML?

HTML stands for HyperText Markup Language. It tells the browser what elements belong on a webpage.

HTML 02

HTML Tags

Tags define elements such as headings, paragraphs, links, buttons, and images.

HTML 03

Headings & Paragraphs

Use <h1> for major headings and <p> for paragraphs.

HTML 04

Links

The <a> tag creates links that allow visitors to move between webpages.

HTML 05

Images

The <img> element lets you display images on your webpage.

HTML 06

Lists

Use ordered and unordered lists to organize information for visitors.

🎨 CSS — Design Your Website

CSS controls the appearance of HTML elements.

CSS 01

What Is CSS?

CSS stands for Cascading Style Sheets. It controls colors, spacing, fonts, layouts, and animations.

CSS 02

Selectors

Selectors tell CSS which HTML elements should receive a particular style.

CSS 03

Colors & Fonts

CSS can change text color, background color, font size, font family, and more.

CSS 04

Box Model

Every HTML element can have content, padding, borders, and margins.

CSS 05

Flexbox

Flexbox makes it easier to arrange elements horizontally and vertically.

CSS 06

Responsive Design

Responsive design allows websites to work properly on phones, tablets, and computers.

⚡ JavaScript — Make It Interactive

JavaScript allows webpages to respond to users and perform actions.

JS 01

What Is JavaScript?

JavaScript is a programming language that can make websites interactive.

JS 02

Variables

Variables store information that your program can use later.

JS 03

If / Else

Conditional statements allow programs to make decisions based on information.

JS 04

Functions

Functions group instructions together so you can run them when needed.

JS 05

Events

Events allow JavaScript to respond when someone clicks or interacts with a page.

JS 06

Arrays

Arrays allow programs to store multiple pieces of information in one collection.
