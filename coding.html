📚 What You're Learning

Understand the purpose behind the code, not just what to type.

🧱 HTML Structure

HTML creates the elements that make up your webpage. 

<h1>
    Hello World
</h1>

<p>
    My website!
</p>

🎨 CSS Design

CSS controls how your HTML elements look and are arranged. 

h1 {
    color: cyan;
}

body {
    background: black;
}

⚡ JavaScript

JavaScript adds behavior and allows your page to react to actions. 

function sayHello() {

    alert("Hello!");

}
