📚 What You're Learning

Everything you create in the lab teaches you real web development concepts.

🧱 HTML Structure

HTML creates the elements that appear on a webpage. 

<h1>Hello World</h1>

<p>My website!</p>

🎨 CSS Design

CSS changes how those elements look and how the page is arranged. 

h1 {
    color: cyan;
}

body {
    background: black;
}

⚡ JavaScript

JavaScript lets your website respond to actions. 

function sayHello() {
    alert("Hello!");
}
